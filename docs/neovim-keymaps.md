# Neovimの設定・切替キーマップ

`<leader>` はSpace。以下はノーマルモードで使う。
`<leader>,` は現在のバッファ・ウィンドウの設定、`<leader>.` はLSP・エディタ全体の設定をまとめる。
プレフィックスを入力して待つとwhich-keyで候補を確認できる。

## `<leader>,`：バッファ・表示設定

| キー | 操作 |
| --- | --- |
| `,w` | 行の折り返しを切替 |
| `,n` | 行番号表示を切替 |
| `,r` | 相対行番号表示を切替 |
| `,h` | LSPのinlay hintsを切替 |
| `,s` | スペルチェックを切替 |
| `,c` | conceal（記号などの省略表示）を切替 |
| `,T` | Treesitterのハイライトを切替 |
| `,i` | インデント幅を切替（2 / 4） |
| `,<Tab>` | インデント文字を切替（space / tab） |
| `,<Enter>` | 改行コードを切替（LF / CRLF） |
| `,f` | ファイルタイプを選択 |
| `,,` | 現在のファイルパスをコピー |

表のキーの前にSpaceを押す。例えばSpace → , → wで折り返しを切り替える。

## `<leader>.`：LSP・エディタ設定

| キー | 操作 |
| --- | --- |
| `.l` | 現在のファイルタイプに応じてLSPを切替 |
| `.s` | 手動切替対象のLSPの有効状態とクライアント数を確認 |
| `.d` | 診断表示を切替（LSPプロセス自体は停止しない） |
| `.g` | インデントガイドを切替 |
| `.D` | 非アクティブなスコープの減光表示を切替 |
| `.b` | 背景のlight / darkを切替 |
| `..` | Neovim設定ファイルを検索 |
| `.pp` | プロファイラを切替 |
| `.ph` | プロファイラのハイライトを切替 |

LSP切替は現在のファイルタイプに対応する管理対象サーバー全てに、セッション全体で適用される。
例えばPythonではPyrightとRuffをまとめて切り替える。全て有効なら無効化、1つでも無効なら全て有効化する。
原則デフォルト無効で、自動有効化するサーバーは `lua/lsp_policy.lua` の `default_enabled` に列挙する。
`<leader>lt`でも同じ操作ができる。詳細は [LSPの起動ポリシーと手動切替](neovim-lsp.md#lspの起動ポリシーと手動切替) を参照。

従来の`<leader>u`配下の表示トグルは上記へ移動した。
`<leader>u`単独はUndo履歴（Undotree）の表示切替に使う。

## `<leader>s`：ほかの操作と重複する割当の整理

以下のSnacks Pickerへの割当は削除し、同じ用途の既存操作へ集約した。
表のキーの前にSpaceを押す。

| 削除したキー | 用途 | 使用するキー |
| --- | --- | --- |
| `sd` | 全体の診断一覧 | `xx`（Trouble） |
| `sD` | 現在のバッファの診断一覧 | `xb`（Trouble） |
| `ss` | 現在のバッファのシンボル一覧 | `xs`（Trouble） |
| `sq` | Quickfix一覧 | `xq`（Trouble） |
| `sl` | Location List一覧 | `xL`（Trouble） |
| `su` | Undo履歴 | `u`（Undotree） |

ワークスペース全体のシンボル検索（`sS`）など、独立した用途の割当は`<leader>s`配下で利用できる。

## `<leader>v`：デバッグ

Fキーの代わりに、言語共通のデバッグ操作をまとめる。表のキーの前にSpaceを押す。

| キー | 操作 |
| --- | --- |
| `vb` / `vB` | ブレークポイント切替／条件付きブレークポイント |
| `vc` | 開始・構成選択・再開 |
| `vn` | 次の行へ進む（step over） |
| `vi` | 関数の中へ入る（step into） |
| `vo` | 現在の関数から抜ける（step out） |
| `vs` | セッション一覧 |
| `vq` | デバッグ終了 |
| `vu` | DAP UIの表示切替 |

Pythonでは `vb` で停止位置を設定し、`vc` で「Python: 現在のファイル」を選ぶ。
詳細は [デバッグ設定](neovim-lsp.md#デバッグ) を参照。

## 診断・Git差分の移動

`<leader>ln` / `<leader>lp` は次／前の診断へ移動するグローバルキーマップ。
LSP未接続でも使え、Neovimに登録されたLSP以外の診断も対象になる。

Git差分の `]h` / `[h`、プレビューの `<leader><leader>gp` は、Gitsignsが対象バッファに
アタッチした際に登録する。LSPの有効・無効には依存しない。
